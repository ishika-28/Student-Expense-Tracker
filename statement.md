# Project Statement

## Project Title
Student Expense Tracker

## Problem Statement
Students like us frequently make small daily purchases for things like food, travel, shopping, and other necessities. When these expenses aren’t tracked properly, it is tough to figure out where we are spending the money. This project aims to offer an easy way for students to record and review their expenses.

## Scope
This project centers around basic personal expense management through a Java console application. It will allow users to add, view, search, delete, and report on their expenses.

## Target Users
- Majorly the College students.
- Students looking to keep tracks on their daily spending.

## High-Level Features
- Entering expenses
- Viewing expenses
- Searching by category and date
- Deleting expenses
- Generating expense summary reports
- Storing data in files

## Functional Requirements
1. Users should be able to add an expense.
2. The system should display all stored expenses.
3. Users should be able to search expenses by category and date.
4. Expenses can be deleted using their ID.
5. The system should calculate total expenses and categorize them.
6. It should identify the highest expense recorded.
7. Expense records should be saved for future reference.

## Non-Functional Requirements
1. Usability - the menu should be straightforward and easy to navigate.
2. Reliability - the application should handle invalid inputs gracefully without crashing.
3. Maintainability - the program should be organized into separate classes.
4. Error Handling - it should manage invalid amounts, categories, and numeric inputs effectively.
5. Resource Efficiency - the application will utilize simple in-memory collections and a CSV file for storage.

## Expected Outcome
The finished application should offer a clear and organized way for students to keep track of their daily expenses and gain insights into their spending habits through basic reporting.
