# Project Statement

## Project Title
Student Expense Tracker

## Problem Statement
Students often make small daily payments for food, travel, shopping and other needs. When these expenses are not recorded properly, it becomes difficult to know where money is being spent. This project provides a simple way to record and review student expenses.

## Scope
The project focuses on basic personal expense management through a Java console application. It supports adding, viewing, searching, deleting and reporting expenses.

## Target Users
- College students
- Students who want to track daily spending

## High-Level Features
- Expense entry
- Expense viewing
- Category and date search
- Expense deletion
- Expense summary report
- File-based data storage

## Functional Requirements
1. The system should allow a user to add an expense.
2. The system should display stored expenses.
3. The system should search expenses by category and date.
4. The system should delete an expense using its ID.
5. The system should calculate total and category-wise expenses.
6. The system should identify the highest expense.
7. The system should save expense records for later use.

## Non-Functional Requirements
1. Usability - the menu should be simple to understand.
2. Reliability - invalid inputs should be handled without closing the application.
3. Maintainability - the program should be divided into separate classes.
4. Error Handling - invalid amounts, categories and numeric inputs should be handled.
5. Resource Efficiency - the application uses simple in-memory collections and a CSV file.

## Expected Outcome
The completed application should provide a simple and organized method for students to maintain their daily expense records and understand their spending through basic reports.
